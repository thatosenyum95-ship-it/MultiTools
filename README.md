# MultiTools 🧰

All your everyday Android tools in one app.

## Planned tools
- 🧮 Calculator
- 🔦 Flashlight
- 📏 Simple measurement
- 📋 Text & clipboard
- 🔐 Password generator
- 🔄 Unit converter
- 📱 Device information
- 📶 Network information

## Tech stack
- Kotlin
- Jetpack Compose
- Material 3
- Android Gradle Plugin

The project is being developed incrementally, with hardware-dependent features implemented natively on Android.
